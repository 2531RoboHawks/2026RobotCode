# 2026 Robot Code

## Controller Layout

### Driver Controller (Port 0)

| Control | Action |
|---------|--------|
| Left Stick | Drive (field-centric) |
| Right Stick X | Rotate |
| Left Trigger | Slow mode (20% speed) + Run intake rollers + Lock intake arm |
| Right Trigger | Run shooter motor |
| Left Bumper | Lock intake position (hold) |
| Right Bumper | Full shoot pipeline: auto-align + spin up + feed (hold) |
| X Button | Pivot intake down (hold) |
| D-Pad Up | Run sorter + feeder |
| D-Pad Left | Shoot sequence (spins up shooter, then feeds ball) |

### Operator Controller (Port 1)

| Control | Action |
|---------|--------|
| A Button | Auto-align only, no shoot (hold) |
| Y Button | Pivot intake up (hold) |
| X Button | Pivot intake down (hold) |
| B Button | Reverse feeder + sorter (hold) |
| D-Pad Up | Hood flap up (manual) |
| D-Pad Down | Hood flap down (manual) |
|Right bumper|Zero hood|
