# 2026 Robot Code

## Controller Layout

### Driver Controller (Port 0)

| Control | Action |
|---------|--------|
| Left Stick | Drive (field-centric) |
| Right Stick X | Rotate |
| Left Trigger | Slow mode (20% speed) + Run intake rollers |
| Right Trigger | Run shooter motor |
| Left Bumper | Lock intake position (hold) |
| Right Bumper | Limelight auto-align (hold) |
| D-Pad Up | Run sorter + feeder |
| D-Pad Left | Shoot sequence (spins up shooter 1.5s, then feeds ball) |

### Operator Controller (Port 1)

| Control | Action |
|---------|--------|
| Y Button | Pivot intake up (hold) |
| X Button | Pivot intake down (hold) |
| B Button | Reverse feeder + sorter (hold) |
